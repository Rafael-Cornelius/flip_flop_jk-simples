# Flip-flop JK

Estudo de memória e lógica sequencial com dois componentes J-K Flip-Flop.

**Arquivo principal:** [flip-flop-jk.circ](circuitos/flip-flop-jk.circ)

## Como abrir

1. Baixe este repositório e descompacte a pasta.
2. Abra o Logisim; o arquivo foi salvo na versão 2.7.1.
3. Em **Arquivo → Abrir**, selecione `circuitos/flip-flop-jk.circ`.
4. Use a ferramenta de interação para alterar as entradas e observar as saídas.

## Adicionar ou atualizar

Salve o circuito em `circuitos/`, usando letras minúsculas e hífens.
Para uma evolução do mesmo circuito, atualize o arquivo existente.
Se precisar de imagens ou enunciados, crie `docs/`.
